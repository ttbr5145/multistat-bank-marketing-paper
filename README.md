## 一、研究问题与主要结论

本文以葡萄牙某银行 2008 年 5 月至 2010 年 11 月电话直销活动的 45211 条客户记录为对象，回答三个问题：哪些因素显著影响认购；这些因素能否在拨号前获得；客户能否按行为特征分群并匹配不同策略。

核心结论：

1. **历史响应行为最稳定。** 上次营销成功者本次认购率 64.73%，控制其他变量后优势比 9.20（95% CI 7.96~10.64）。
2. **外呼时点是可管理变量。** 3 月优势比 2.88，5 月仅 0.38；而 5 月恰是拨打量最大的月份（占 30.45%）。
3. **负债结构形成实质约束。** 住房贷款、个人贷款分别把优势比压到 0.558 与 0.659。
4. **通话时长最强，但不能事前使用。** 计入时长后 AUC 由 0.7491 升至 0.9037，差距即信息泄漏造成的虚高，故该模型仅用于复盘。
5. **客户可分四类。** 高互动群体占 9.10%，认购率 45.52%；占 54.77% 的年轻低余额群体仅 7.67%。

## 五、复现方式

### 1. 环境准备

```powershell
# 确认 R 可用（本机未加入 PATH，用绝对路径调用）
& "D:\Program Files\R\R-4.6.0\bin\Rscript.exe" --version
```

### 2. 安装依赖

```r
install.packages(c("readxl", "openxlsx", "pROC", "ggplot2", "dplyr", "cluster", "car"))
```

### 3. 跑分析

```powershell
& "D:\Program Files\R\R-4.6.0\bin\Rscript.exe" --encoding=UTF-8 --vanilla `
  "D:\AI\多统上机\小论文\分析\01_探索与建模.R"
```

脚本会重建 `分析/图`、`分析/表` 与 `01_分析日志.txt`。随机过程固定 `set.seed(20261122)`，结果可复现。

### 4. 转 PDF

```powershell
$w = New-Object -ComObject Word.Application; $w.Visible = $false
$d = $w.Documents.Open("...\多统小论文_吴桐_2024213023.docx", $false, $false)
$d.SaveAs2("...\多统小论文_吴桐_2024213023.pdf", 17)
$d.Close($false); $w.Quit()
```

> 中文图形必须显式指定 `family = "SimSun"`，否则 Windows 默认设备字体可能把中文渲染成方块。

## 八、课程格式要求摘要

摘自 `小论文格式说明.docx`，逐条落实如下：

**结构**
- 标题 ≤ 20 字；中文摘要 ≤ 500 字，独立自含，不出现图表、冗长公式与非公知符号
- 关键词 3~8 个，分号分隔，冠以“关键词：”
- 层次 ≤ 4 级：`1` / `1.1` / `1.1.1` / `(1)`；图表编号“图1”“表1”
- 公式用阿拉伯数字连续编号，正文引用写作“式(1)”
- 参考文献实引，按正文出现次序，序号左顶格 `[1]`，格式遵循 GB/T 7714-2015
- 英文摘要置于参考文献之后
- 全文字符数约 15000

**排版**
- 正文小四号宋体，单倍行距，单栏，无多余空行
- 页边距中等（约 2 cm），页脚加页码
- 图表标题小五号宋体，表格数据对齐、小数位数统一
- 存为 Word/WPS，提交学习通须转 PDF

> 说明文档正文条款与样例稿存在不一致（样例四级标题写作 `1.1.1.1`，条款规定用 `(1)`）。本项目一律以条款为准，并已在排版时回避该层级。
